# Elytra Space (Fabric, Minecraft 26.2, client-side)

Ab konfigurierbarer Hoehe (Standard 350 -> 900) wird waehrend des Elytra-Flugs der Himmel schwarz,
Sterne werden sichtbar, und am Horizont bleibt ein blauer Atmosphaerenrand. Voxy-kompatibel.
Config: `config/elytra_space.json`.

Build: `./gradlew build` -> `build/libs/elytra-space-1.0.0.jar`
Test:  `./gradlew runClient`
Quellen fuer Verifikation: `./gradlew genSources`
